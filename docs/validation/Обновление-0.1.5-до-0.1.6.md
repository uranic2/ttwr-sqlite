# Проверка обновления 0.1.5 → 0.1.6 — 14 ноября 2026 года

Все три обновления через окно программы прошли успешно. База игроков и настройки сохранились.

| Исходный комплект | Среда Java | Папка | Результат |
|---|---|---|---|
| Со встроенной Java | Temurin 25.0.5 x64 | Без кириллицы | Успешно |
| Без встроенной Java | Temurin 8u472 x32 | Без кириллицы | Успешно |
| Со встроенной Java | Temurin 25.0.5 x64 | Кириллица и пробелы | Успешно |

## Как выполнялась проверка

Использованы сохранённые оригинальные ZIP 0.1.5. Их SHA-256 сверены с опубликованными ранее контрольными суммами, зафиксированными в сценарии проверки. Каждая копия распакована в отдельную новую папку `.local`; рабочие данные пользователя не использовались.

В каждом профиле созданы 301 синтетический игрок, одна историческая запись рейтинга, служебные метаданные, 16 нестандартных настроек и контрольные файлы в `Tours` и `Backup`.

Запускался оригинальный EXE 0.1.5. Тестовый Java-agent нажимал штатные кнопки Swing и наблюдал состояние окна, не изменяя классы программы. Через меню «Справка» выполнялась проверка релиза на настоящем GitHub. Программа сама скачивала 0.1.6, проверяла архив, штатно закрывалась, устанавливала обновление и запускала 0.1.6. Ответы GitHub и загрузка не подменялись.

## Что подтверждено

- Сохранены все строки и столбцы таблиц `players` и `metadata`: 301 игрок в текущем списке и одна запись в отдельной области истории. Проверены Unicode, рейтинги, статистика и служебные значения.
- Логический SHA-256 базы одинаков до и после во всех трёх случаях: `375643510deb1ac9efa37b7e2178622a768036f70127e9b0c577fc728d9393e2`.
- `PRAGMA integrity_check` вернул `ok`.
- Сохранённый при закрытии 0.1.5 файл `ttwr.cfg` совпал побайтно с файлом при старте 0.1.6 и после её штатного закрытия. Все 16 выбранных настроек дополнительно сверены в работающих окнах обеих версий.
- При первом запуске исходной 0.1.5 геометрия окна в искусственном профиле адаптировалась к экрану. Побайтное сравнение обновления выполнялось после штатного сохранения старой версией: между ним, стартом 0.1.6 и её закрытием изменений нет.
- Встроенная `runtime` сохранилась по контрольной сумме всех файлов. В варианте с системной Java папка `runtime` не появилась; при запуске сохранилась Java x32.
- Контрольные файлы в `data/Tours` и `data/Backup` не изменились.
- Все 25 файлов установленного комплекта проверены по манифесту релиза. В архиве программы и работающем окне подтверждена версия 0.1.6.
- Установщик сохранил резервную копию исходного EXE и `app/ttwr.dat` 0.1.5; их хеши совпали с исходными.
- Оба процесса Java в каждом переходе завершились с кодом 0. После закрытия нет `Players.sqlite-wal` и `Players.sqlite-shm`.

Проверка выполнена на текущей Windows x64 и синтетической базе. Она подтверждает сохранность данных в этих сценариях; другие ОС и произвольные пользовательские профили в данный прогон не входили.

## Повторение

Нужны оба оригинальных ZIP 0.1.5 в `releases`, доступный публичный релиз 0.1.6, JDK 17+ и Java 8 x32. Укажите свои пути:

```powershell
python scripts/test-live-upgrade.py --jdk 'C:\Program Files\Java\jdk-25' --java32 'C:\Tools\jre8-x32' --from-version 0.1.5 --target-version 0.1.6 --cyrillic
```
