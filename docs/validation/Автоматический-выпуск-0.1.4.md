# Автоматический выпуск 0.1.4 — 14 ноября 2026 года

[Запуск GitHub Actions по тегу v0.1.4](https://github.com/uranic2/ttwr-sqlite/actions/runs/43578720894) завершился успешно. Публикацию выполнила задача workflow, без ручной загрузки файлов.

- Сборка выполнена на Windows runner из чистого клона, включая оригинальный `vendor/upstream/ttwr.dat` с проверкой SHA-256.
- Установлены Temurin JDK 25 x64, JRE 8 x32 и JRE 25 x64; Zig загружен по зафиксированной контрольной сумме.
- Выполнены проверки SQLite, транзакций, закрытия, обновления программы, интерфейса и перезапуска установщиком. Папка с кириллицей, пробелами и японскими символами обработана корректно на англоязычной Windows.
- Оба ZIP распакованы на runner: проверены манифест, версия, пустая БД, Java x32 в варианте system-java и комплектная Java x64 в полном варианте.
- Релиз создан как черновик, оба ZIP загружены и проверены по SHA-256, затем релиз опубликован.
- После публикации оба ZIP отдельно скачаны без авторизации, повторно проверены все файлы по манифесту и целостность пустой БД. Удалённого документа и ссылок на него в Markdown комплекта нет.
- Старые релизы 0.1.1, 0.1.2 и 0.1.3 удалены; их описания и проверенные комплекты сохранены локально как резервные копии. История Git не изменялась.

Для следующего выпуска нужно обновить `VERSION`, README и CHANGELOG и отправить новый тег. Ручной запуск workflow выполняет сборку без публикации.
