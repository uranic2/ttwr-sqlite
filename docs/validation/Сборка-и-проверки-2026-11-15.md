- Ссылки в упакованных документах проверены; ссылки на исходные документы с пробелами в имени преобразуются в корректные GitHub URL. Имена установленных документов сохранены для совместимости обновлятора.

## Проверки

На Java 25.0.1 x64 и Java 8u321 x64 прошли по 39 сценариев — всего 78:

- 17 основных сценариев хранилища, транзакций, завершения, профиля, импорта, восстановления, даты публикации, сетевого потока, показателей и обновлений.
- MainMenuUiChecks — настоящее меню и окно информации о БД.
- DatabaseStatusUiChecks update/restart — обновление даты и статуса с повторным запуском.
- DbPackageRecoveryFailureChecks gui — отказ запуска при повреждённой резервной копии.
- PlayerUpdateUiChecks button/escape/close/success/unknown/error/import — прогресс игроков, отмена, повтор, неизвестный размер, обрыв и импорт.
- ProfileFirstRunUiChecks accept/decline — решение об импорте при первом запуске.
- ProgramUpdateUiChecks current/cancel/storage — проверка версии, отмена установки и очистка хранилища после старта.
- DownloadUiChecks button/escape/close/success/error — прогресс программы, отмена и очистка с сохранностью данных.
- UpdateHelperSmoke — отдельные процессы, ожидание блокировки, установка, резервирование, Unicode-пути и native-перезапуск. Проверка прошла после записи полного маркера.

## Ограничения

Те же тестовые классы и режимы запущены напрямую через JDK с проверкой кодов завершения и ограничением времени каждого процесса. package.ps1 выполнен штатно.
