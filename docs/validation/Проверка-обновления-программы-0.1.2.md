# Проверка обновлений программы — 14 ноября 2026 года

- Сборка: JDK 25, Java-классы с `--release 8`; Windows-запускатель не менялся.
- Полный набор проверок пройден на Java 25 x64 и Java 8u472 x32, включая существующие проверки SQLite и закрытия.
- Новые проверки: числовое сравнение версий, исключение предварительных релизов, URL и SHA-256, HTTP-ошибки, защита путей ZIP, внутренний манифест, версия архива, резервирование и откат при имитации ошибки диска.
- Реальная отдельная JVM удерживала блокировку приложения. Установщик дождался закрытия, сохранил резервную копию, заменил тестовые файлы и запустил native EXE, оставивший отметку о перезапуске. Использованы пути с кириллицей и пробелами; пользовательские `data` и `runtime` в тестовой папке не изменились.
- В исходном окне TTWR проверены пункт меню «Справка», номер `v 0.1.2` в статусной строке, сообщение ручной проверки и отмена установки через штатный диалог выхода после загрузки и проверки имитированного релиза.
- После расширенного аудита удалены старые сетевые задания проверки программы и загрузки установщика; проверка исполняемых инструкций не находит вызовов старого обновлятора. Обновление списка игроков сохранено.
- Новый значок с пером SQLite включён в Java-архив и native EXE. Проверено извлечение значка из EXE и загрузка значка в настоящем окне приложения.
- Проверки интерфейса и установки используют изолированные профили, синтетические файлы и имитацию HTTPS; рабочая база не затрагивается.
- Отдельно через настоящий общедоступный GitHub API без авторизации получен релиз 0.1.1 и загружен его ZIP `system-java`; размер 14 172 231 байт и SHA-256 совпали с метаданными релиза.

На момент этих проверок 0.1.2 ещё не опубликована. Установка будущего реального релиза 0.1.3 из GitHub не проверялась; соответствующий поток загрузки и установки проверен локальными сценариями. Цифры производительности из прежних отчётов заново не измерялись.
