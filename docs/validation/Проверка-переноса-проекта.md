# Проверка переноса проекта — 12 ноября 2026 года

- Репозиторий сохраняет существующий origin; коммит, тег и отправка в GitHub не выполнялись.
- Java-классы и Windows-запускатель пересобраны в новой структуре. Входной файл — оригинальный архив TTWR, а не промежуточная модифицированная сборка.
- Зависимости скачаны по lock-файлу, их SHA-256 проверены. Сборка использует JDK 25, публичный ASM 9.7.1 и Zig 0.17.1.
- Полный набор проверок прошёл на Java 25 x64 и Java 8u472 x32: 300 синтетических игроков, страницы и Unicode, транзакции и откат, исторические рейтинги, резервирование, смена пути, закрытие SQLite, перенос профиля и имитация обновления HTTPS.
- При проверке x32 найден и исправлен редкий NullPointerException очистки слабого кеша при откате. Добавлен детерминированный регрессионный сценарий.
- ZIP-комплекты отдельно распакованы; проверены контрольные суммы файлов и запуск native EXE. В варианте system-java загружен настоящий SQLite-драйвер x32; в полном комплекте — комплектная Java 25 x64.
- Стартовая база содержит 0 игроков, целостность — ok. В распространяемых ZIP нет рабочей папки data.
- В набор файлов для Git не входят vendor, кеш зависимостей, build, dist, releases, пользовательские базы и настройки. Проверка исходников на явные приватные пути и типовые секреты пройдена.

SHA-256 актуальных ZIP находятся в `release-checks.json` этой папки и в локальном `releases/SHA256SUMS.txt`. Исторические отчёты относятся к предыдущим этапам; новые проверки не используют реальный каталог игроков.
