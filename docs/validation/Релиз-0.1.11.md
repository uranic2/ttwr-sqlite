## Свидетельства и ограничения

Загруженные ZIP, результаты JSON, журнал CI, проверочные сценарии и копии запусков сохранены в `.local/release-0.1.11-1794766303650`. Подробные журналы CI также доступны по ссылке запуска выше.

CI проверяет имитацию HTTPS и отдельный установщик. Реальный переход опубликованной версии 0.1.10 → 0.1.11 через пользовательское окно обновления и настоящая загрузка игроков с сервера в этом выпускном прогоне не выполнялись. Это не проверка на 32-разрядной Windows; Java x32 проверена на Windows x64.

Отдельные существовавшие до выпуска локальные изменения документов проверки офлайн-запуска оставлены вне коммитов этой задачи.
