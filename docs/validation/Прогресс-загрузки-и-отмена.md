# Окно загрузки обновления и отмена — 14 ноября 2026 года

Изменения включены в версию 0.1.9. Описанные локальные проверки выполнены до повышения номера версии; при выпуске GitHub Actions повторяет полный набор проверок. Опубликованные комплекты предыдущих версий не заменяются.

## Интерфейс

В окне показаны процент загрузки, скачанный и общий объём в КБ (1024 байта), скорость за последние 2 секунды, средняя скорость за весь сеанс загрузки, прошедшие секунды и оценка оставшихся. Показатели обновляются раз в секунду. Скорости рассчитываются по монотонным часам, без зависимости от перевода системного времени. До накопления данных и при нулевой текущей скорости оценка времени обозначается «—».

После получения архива показатели загрузки фиксируются; строка состояния отдельно сообщает о проверке SHA-256 и подготовке файлов. После успешной проверки остаётся прежнее предложение закрыть программу и установить обновление.

В «Справка → О программе» добавлена ссылка `https://github.com/uranic2/ttwr-sqlite`. Она отображается подчёркнутой, имеет курсор ссылки и вызывает `Desktop.browse()` в фоновом задании, чтобы открыть системный браузер. Если браузер недоступен, показывается адрес и сообщение об ошибке.

## Отмена

Кнопка «Отмена», Esc и крестик окна используют один механизм: запрос отмены, прерывание рабочего потока и отключение активного соединения вне потока Swing. Очистка выполняется после закрытия потоков файла. Основное окно снова включается после завершения операции и удаления её временной папки.

Удаляются ZIP, частично распакованный образ и другие временные файлы только текущей загрузки. Последняя резервная копия и незавершённые установки других операций сохраняются. Проверяются границы каталога и отсутствие ссылок/junction. При ошибке удаления показывается папка оставшихся файлов; успешная очистка не заявляется.

Учтена отмена после возврата фонового задания, но до обработки результата в интерфейсе: в этом случае готовая временная папка тоже удаляется, предложение установки не показывается. Существующий файл не удаляется, если создание ZIP с `CREATE_NEW` завершилось ошибкой.

## Проверки

Полный набор с GUI и native-перезапуском прошёл на Java 25.0.1 x64 и Temurin Java 8u472 x32 на текущей Windows x64.

- `DownloadChecks`: двухсекундное окно, средняя скорость, оценка времени, остановка передачи, фиксация итогов и отрицательные значения монотонных часов. Часы для расчётов задаются явно.
- Зависшие заголовки и тело HTTP-ответа: тестовое чтение игнорирует прерывание потока и завершается после отключения соединения. Проверены ранняя и поздняя отмена, отсутствие частичного ZIP, сохранность существующего файла и старой копии.
- `DownloadUiChecks`: настоящее окно TTWR с медленным имитированным HTTPS. Проверены кнопка отмены, Esc, крестик, успешная загрузка и обрыв связи; наличие показателей и интервал обновления 1000 мс.
- После каждой операции проверены удаление её временной папки, неизменность базы, настроек и ранее существовавшей резервной копии. Результаты и снимки окна сохраняются в отдельных тестовых профилях.
- Отдельно собран и осмотрен диалог «О программе» с новой ссылкой. Проверены наличие действия ссылки и создание диалога на Java 25 и Java 8. Фактический запуск пользовательского браузера автоматический тест не выполнял.

Все сетевые ответы в этих проверках имитируются; реальные данные пользователя не использовались. Это проверки поведения, а не замеры скорости публичного GitHub или сети пользователя.
