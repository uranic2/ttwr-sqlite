# BL-10. Гиперссылка на профиль игрока на сайте TTW — P2

**Статус: запланировано.**

## Цель

Добавить в окно профиля игрока гиперссылку на его страницу на сайте TTW. Пользователь должен переходить из программы к нужному профилю без ручного копирования персонального ID и поиска игрока на сайте.

## Формирование адреса

Адрес строится по шаблону:

```text
https://r.ttw.ru/players/?id=<персональный ID>
```

Персональный ID передаётся в **шестнадцатеричном формате**, строчными буквами, без префикса `0x`. Источник значения — ID текущего игрока в модели, а не имя игрока, номер строки списка или текст другого элемента интерфейса.

Пример из исходной постановки:

| Персональный ID | Адрес страницы |
|---|---|
| `3ad2651` | `https://r.ttw.ru/players/?id=3ad2651` |

В программе `Player.GetID()` возвращает целочисленное значение `profile.ID`; для построения адреса подходит `Integer.toHexString(player.GetID())`. Нельзя подставлять в URL десятичное представление этого числа или повторно интерпретировать отображаемую строку ID как десятичное число.

## Поведение интерфейса

1. В окне профиля добавить отдельную ссылку **«Профиль на сайте TTW»** в блоке основных данных игрока. Подчёркивание и курсор руки должны показывать, что элемент можно нажать; в подсказке отображается полный адрес.
2. Нажатие открывает сформированный URL в браузере по умолчанию. Ссылка должна быть доступна также с клавиатуры.
3. Для каждого открытия окна адрес формируется из ID именно того игрока, чей профиль показан. При переходе к другому игроку ссылка не должна сохранять прежний ID.
4. Открытие браузера не закрывает окно профиля, не подтверждает редактирование и не сохраняет введённые изменения. Кнопки подтверждения и отмены продолжают работать по прежним правилам.
5. Если игрок ещё не создан, объект игрока отсутствует или его ID не положительный, ссылка недоступна. Рядом или в подсказке указывается причина: **«Профиль недоступен: не задан ID игрока»**. Открывать адрес с `id=0`, отрицательным или пустым значением нельзя.
6. Если системный браузер недоступен или запуск завершился ошибкой, показать понятное сообщение и сформированный URL, чтобы его можно было скопировать. Ошибка не должна блокировать дальнейшую работу с профилем.

Положительный ID локально созданного игрока не гарантирует наличие опубликованной страницы. Функция формирует адрес; наличие и содержимое страницы определяет сайт. Дополнительная проверка страницы по сети при открытии окна профиля не требуется. При отсутствии интернета ошибку загрузки страницы показывает браузер.

## Ограничения реализации

- Использовать HTTPS и фиксированный адрес `https://r.ttw.ru/players/` с единственным параметром `id` в указанном формате.
- Запуск браузера выполнять через системный механизм, например `Desktop.browse()`, с обработкой неподдерживаемого действия и ошибок. В проекте уже есть аналогичная ссылка в окне «О программе».
- Работа по запуску браузера не должна задерживать поток интерфейса.
- Нажатие ссылки не изменяет ID, данные игрока, SQLite-базу, настройки или состояние сохранения турнира.
- Сохранить совместимость с Java 8+ x32/x64 и существующими способами открытия окна профиля, включая вызов из списка игроков и турнира.

## Критерии приёмки

- [ ] Для игрока с персональным ID `3ad2651` открывается ровно `https://r.ttw.ru/players/?id=3ad2651`.
- [ ] Числовой ID преобразуется в шестнадцатеричную строку: в адрес не попадает его десятичное представление.
- [ ] При последовательном открытии разных игроков ссылки содержат соответствующие им ID.
- [ ] Ссылка визуально различима, имеет подсказку с адресом и доступна мышью и клавиатурой.
- [ ] Адрес открывается в браузере по умолчанию; интерфейс программы остаётся отзывчивым.
- [ ] Для отсутствующего или неположительного ID ссылка не выполняет переход.
- [ ] При ошибке запуска браузера показаны сообщение и URL; окно профиля остаётся рабочим.
- [ ] После нажатия ссылки несохранённые изменения полей остаются в окне. Последующая отмена не сохраняет их в БД.
- [ ] Работа ссылки проверена при открытии профиля из списка игроков и из турнира.

Формирование URL и обработку ошибок можно проверить автоматически с подставным обработчиком открытия адреса. Переход в установленный браузер проверить вручную на отдельной тестовой копии программы. Проверки не должны использовать рабочую базу пользователя или требовать наличия реальной страницы для каждого синтетического игрока.
