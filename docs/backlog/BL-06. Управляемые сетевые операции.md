# BL-06. Управляемые сетевые операции — P2

**Статус: частично реализовано в 0.1.9.** Для обновления программы добавлены показатели, отмена и очистка временных файлов. В 0.1.10 BL-11 добавляет таймауты, прогресс и отмену загрузки XML игроков и сопутствующих файлов базы. Старые фоновые проверки наличия обновлений остаются вне этой доработки. См. [отчёт BL-11 / BL-13](../validation/Проверка-BL-11-и-BL-13.md). Исходная постановка ниже сохранена.

**Наблюдение.** Загрузчик XML не задаёт явные таймауты подключения и чтения. Во время загрузки обновления программы главное окно отключено, прогресс неопределённый, кнопки отмены нет. У клиента обновлений программы таймауты уже есть.

**Пользовательский сценарий.** При плохом соединении непонятно, продолжается ли загрузка и сколько осталось ждать.

**Предложение.** Добавить таймауты для XML, отмену загрузки, отображение полученного объёма и понятные сообщения при обрыве связи. Отмена должна корректно закрывать соединение и очищать только временные файлы своей операции.

**Критерий проверки.** Смоделировать недоступный сервер, зависшее чтение, обрыв, отсутствие длины ответа и отмену. Рабочая БД, настройки и установленная программа сохраняются.

Код: [StreamingPlayers.java](../../src/main/java/ttr/StreamingPlayers.java); [ProgramUpdates.java](../../src/main/java/ttr/updates/ProgramUpdates.java), `download()`; [ReleaseClient.java](../../src/main/java/ttr/updates/ReleaseClient.java).
