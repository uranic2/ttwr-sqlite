# BL-05. Перелистывание и подсчёт результатов — P2

**Наблюдение.** Каждая загрузка страницы отдельно считает количество подходящих игроков и выполняет выборку с `LIMIT … OFFSET`.

**Пользовательский сценарий.** Дальние страницы и сложная сортировка могут требовать больше работы, чем первые страницы того же списка.

**Предложение.** Сохранять количество результатов до изменения фильтра или базы. Для последовательного перелистывания рассмотреть выборку относительно последней строки предыдущей страницы. Индексы подбирать по реальным планам запросов, а не добавлять заранее.

**Критерий проверки.** Нет пропусков и повторов при одинаковых значениях сортировки; сохранён устойчивый порядок по ID. Проверены все сортировки, фильтры, изменение БД и исторические рейтинги. Сравнить время первой, средней и дальней страниц.
