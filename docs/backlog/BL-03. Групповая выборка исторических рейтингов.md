# BL-03. Групповая выборка исторических рейтингов — P1

**Наблюдение.** После получения страницы исторические данные запрашиваются отдельно для каждого из 100 игроков. Поиск может проходить через несколько рейтинговых списков. При первом обращении к списку создаётся его снимок в SQLite.

**Пользовательский сценарий.** Открытие списка на выбранную дату, сортировка и перелистывание могут замедляться при большой истории рейтингов.

**Предложение.** Получать исторические данные сразу для всей страницы. Отделить подготовку снимков от отображения, при необходимости показывать её прогресс. Сохранить правила выбора даты, приоритет списков и расчёты для фиксированных рейтингов.

**Критерий проверки.** Рейтинги, статистика и порядок строк совпадают с текущим поведением на граничных датах. Число запросов не растёт пропорционально числу игроков страницы; отдельно измерены первое открытие и повторное обращение.
