# BL-02. Тяжёлые операции вне потока интерфейса — P1

**Наблюдение.** После редактирования игрока заново запрашиваются все страны, регионы и города. Просмотр турниров игрока перебирает рейтинговые списки и турниры в обработчике кнопки.

**Пользовательский сценарий.** На большой истории окно может переставать отвечать после сохранения профиля или при открытии списка турниров.

**Предложение.** Выполнять длительную работу в фоне, обновлять справочники только при изменении местоположения и сохранять выделение игрока при обновлении таблицы. Учесть согласованность данных и доступ к старым объектам из разных потоков.

**Критерий проверки.** Во время выполнения операции окно продолжает отвечать; результаты корректны после отмены или изменения данных. Изменение рейтинга без изменения местоположения не вызывает полного обновления справочников.

Код: [PlayersListPanel.java](../../src/main/java/ttr/UI/PlayersListPanel.java), методы `choose()`, `addPlayer()`, `showTours()`; [DBPlayers.java](../../src/main/java/ttr/DBPlayers.java), метод `UpdatePlayerLocationList()`.
