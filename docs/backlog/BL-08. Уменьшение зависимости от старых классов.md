# BL-08. Уменьшение зависимости от старых классов — P3

**Наблюдение.** Прямые изменения публичных полей поддерживаются перехватчиками и преобразованием байткода. Метод `GetArray()` способен материализовать весь список игроков в памяти. Наличие метода само по себе не подтверждает его использование в обычном пользовательском сценарии.

**Предложение.** Проверить оставшиеся вызовы полного перебора и постепенно заменять их явными операциями хранилища. Упрощать совместимость по отдельным пользовательским операциям, сохраняя поведение старых классов и форматов.

**Критерий проверки.** У критичных операций понятны границы транзакций и правила отката. Обычные действия со списком не загружают всю базу в память. Для каждого заменённого пути проверены сохранение, отмена, повторное открытие и совместимость.
