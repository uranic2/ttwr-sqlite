# Как запустить две копии TTWR SQLite

TTWR SQLite допускает один запущенный экземпляр на папку установки. Чтобы одновременно вести два турнира, распакуйте программу в две разные папки. Каждая копия создаст собственную папку `data` рядом с EXE и будет хранить в ней настройки, базу игроков и турниры.

## Почему второй запуск из одной папки заблокирован

При повторном запуске из той же папки TTWR SQLite сообщает «Программа уже запущена или выполняется её обновление». Приложение и установщик берут эксклюзивную блокировку Windows на `data/application.lock`. Пока работает приложение, установщик ждёт его выхода. Пока работает установщик, запуск приложения заблокирован. Сам файл может оставаться после выхода. Удаление этого файла не требуется. [Обновление программы](../Обновление-программы.md)

У двух окон с общей папкой `data` возникли бы следующие конфликты.

- **Настройки и турниры.** Оба экземпляра сохраняли бы общий `ttwr.cfg`, включая список турниров для восстановления. Последнее закрывшееся окно могло бы перезаписать список другого окна. При работе с одним турниром оба окна могли бы перезаписать его XML или автосохранение своими результатами. [Форматы файлов TTWR](../Архитектура-оригинального-TTWR.md)
- **Правки игроков.** SQLite координирует запись в один файл, а окна работают со своими объектами игроков. Уже открытая карточка может содержать устаревшие данные. Если два экземпляра успеют выбрать один и тот же свободный ID, более поздняя запись может заменить первую. [Запись игроков в SQLite](../../src/main/java/ttr/SqlitePlayersStore.java)
- **Загрузка и импорт каталога.** Программа заменяет четыре файла базы, включая `Players.sqlite`. На Windows открытая база во втором процессе может помешать замене и откату. Если откат сразу не удался, программа использует `data/db-package.pending` для восстановления при следующем запуске. [Обновление списка игроков](../Архитектура.md#как-обновляется-список-игроков)



## Как запустить вторую копию

1. Распакуйте ZIP-комплект целиком в отдельную папку. Например, если первая копия находится в `C:\TTWR\Турнир 1`, распакуйте вторую в `C:\TTWR\Турнир 2`. В каждой папке должны быть свой `ttwr-sqlite.exe` и папка `app`. Комплект со встроенной Java также содержит `runtime`.
2. Запустите `ttwr-sqlite.exe` из второй папки. Первую копию можно оставить открытой. Вторая создаст свою `data`. Если на первом запуске появится предложение импортировать профиль оригинального TTWR, выберите нужный вариант.
3. Если во второй копии создана пустая база, наполните её через **БД игроков → Обновить БД игроков из интернет → Обновить**. Сохраняйте турниры в своей папке `data/Tours` у каждой копии. [Руководство пользователя](../Руководство-пользователя.md)

Если во второй копии нужны уже настроенная база и турниры первой, перед **первым запуском второй копии** дождитесь завершения текущих обновлений и закройте первую. Затем скопируйте её папку `data` целиком рядом со вторым EXE. После этого запустите обе копии. База, турниры и настройки будут независимыми, поэтому последующие изменения и обновления списка игроков выполняются в каждой копии отдельно. Для каждой копии используйте собственные файлы турниров и папку `data` без ссылок на общий каталог.
